# The Infinity Engine — Preview

PREVIEW — NOT THE FULL ENGINE.

This is a static preview, built from scratch in plain HTML, CSS, and JavaScript, so visitors have something real to visit while the full Infinity Engine front is being prepared. It is not the full Engine, and it is not a copy of the Engine's server code.

In this preview: landing, About, a Sand Code sandbox and gallery, a Time Capsule public living message, Careers, a growing Law Library with only entries verified from official sources, a Fusion INFUSE summary from official DOE sources, and a Boats / Off-Signal reference panel.

Not in this preview, and not faked here: sign-in or sign-up, member or back areas, saved creations, forum posting, auctions, live server feeds, or any server feature. The full front will replace this preview wholesale when its files can move.

Second commit — cover page and limited member interface, corrected to lean: the page opens on a lean cover page — hero only: title, slogan, SIS emblem, menu tabs, and an ENTER action. No full sections are stacked on the landing page. ENTER opens a limited member interface that echoes the deck layout in structure only (a simplified status strip, a center stage, and a bottom chat), with only member-safe sections: HOME, ABOUT IT, SAND CODE, TIME CAPSULE, CAREERS, LAW, FUSION, BOATS, SUPPORT. Tabs take the visitor to one page at a time — only the selected section is visible, the rest stay hidden until their tab is clicked. The chat follows the Neverwinter model: tabs at the bottom, input at the bottom, messages stacking upward from the bottom, and the chat dock stays fixed at the bottom above the bottom menu — it never pops to the top. On entering, Agamoss greets the visitor automatically. That chat is canned navigation help only: it is not a live AI, messages do not send anywhere, and nothing typed there reaches a back end. Live AI replies, Ask the Administrator, and Request a Build come with the full front. No deck address, back area, internal option, key, or private data is in this preview.

Sand Code in this preview is matrix green, not gold: green grains #33ff66 on pure black #000000, small grainy dots with size variation and flicker, outline and edge points only, no solid halo, no filled shapes. Gather, scatter, and reform, the slash terminal, the shape picker, and the controls are unchanged in function.
